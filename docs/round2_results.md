# 第二轮实验结果

同一套原生 GQA 内核和选择器比较串行精确、严格推测修复和并集推测修复。`union_overlap` 仍从逐块状态合并，保留预测中的错块并按自身集合校验；本轮没有运行原 PRR 的每头聚合与流式漏块修复内核。`zero_repair_overlap` 只返回选中 ID 和预测状态，不产出注意力结果，用于估计现有双流调度移除修复后的余量。

**这里的 Qwen 使用稠密注意力。** Q/K/V 捕获后，在固定快照上额外运行 Quest 风格的块级 min/max 打分与 `torch.topk`，每块 32 个 token。按当前 Q 各维正负取块 K 的最大或最小值并求内积界；它不是 Qwen 自带的 Top-K 选择阶段。预测采用上一解码步选中 ID，没有实现 EMA。完整路径只指回放的选择、推测和修复，没有接入模型注意力输出，也不代表模型解码延迟或稀疏任务质量。

CUDA event 计时区间内批量回放固定的 Graph，按批总时间除以每批回放次数得到样本。p50、p95 取这些批均值的分位数。报告区间跨不同测点，速度比始终对同一测点配对。计时排除编译、图捕获、元数据生成和预测列表构造。比较完整路径性能时，以相邻基线的配对复测为准。独立测量用于观察完整配置和分阶段开销。

## 与第一轮及 PRR 的比较范围

第一轮使用展开 GQA 的回放或合成多头输入，Graph 计时采用逐次 event。第二轮同时改变布局、内核和计时方式，宜采用同轮配对比值。第二轮的 p95 描述同一固定输入的批均值波动。

第一轮 compact 的慢速有明确的实现成本。它多做一遍 Q/K 统计，分组后按头聚合低质量块。相同 Graph 的单次与批量计时差异远小于长上下文下旧 compact 与旧串行精确的差距。切到原生 GQA 的 saved 路径后，严格和并集完整路径的耗时接近。去掉严格错块过滤只能改变修复的一部分，选择和推测的并发成本、漏块计算及输出合并仍消耗余量。轻量修复在无漏块的合成条件下降低了这部分成本，真实回放的漏块使每头顺序处理的代价变大。

此处 FlashInfer 页式基线的增益是在固定形状、共同选择器与 A100 上测得的。PRR 使用专门的 Hopper 内核、EMA 和按选择窗口调节的推测预算，并报告真实解码。现有结果解释了原型当前瓶颈，无法把与 PRR 的性能差距归到一种因素。
